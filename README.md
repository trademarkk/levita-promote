# Обучение промоутера LEVITA

Интерактивный курс для подготовки промоутера к первой смене:

- 8 последовательных учебных модулей;
- карусель с примерами целевой аудитории 25+;
- 4 виртуальных диалога с удачными и неудачными исходами;
- 10 интерактивных сложных ситуаций;
- правила сбора контакта и выдачи листовки только после появления интереса;
- банк из 35 вопросов, из которого в каждой попытке выбираются 25;
- проходной результат 22 из 25 без ошибок в критических правилах;
- ровно 2 попытки и итоговый экран для скриншота куратору;
- PDF-шпаргалка.

Результаты теста не передаются на сервер. Число попыток и последний результат
хранятся только в браузере промоутера (`localStorage`). После теста промоутер
отправляет куратору скриншот итогового экрана.

## Локальный запуск

Понадобится Node.js 22 или новее.

```powershell
npm ci
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Проверка

```powershell
npm run lint
npm test
npm run vercel-build
```

## Будущая публикация на Vercel

Проект подготовлен как Next.js-приложение. Файл `vercel.json` задаёт отдельную
команду сборки для Vercel. При импорте репозитория Vercel должен автоматически
определить фреймворк Next.js.

При необходимости можно добавить переменную `NEXT_PUBLIC_SITE_URL` с полным
адресом опубликованного сайта. Она используется для карточки ссылки в
мессенджерах.

## Основные файлы

- `app/page.tsx` - содержание курса, интерактив и тест;
- `app/globals.css` - оформление;
- `public/promoter-cheatsheet.pdf` - PDF-шпаргалка;
- `public/photo-credits.txt` - источники и лицензии фотографий;
- `RESEARCH.md` - исследования и решения, на которых построен онбординг;
- `scripts/generate_cheatsheet.py` - генератор PDF-шпаргалки.
